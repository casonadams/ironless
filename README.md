# ironless

A dumbbell-only workout tracker for floor and standing exercises: no bench, no rack. Built with
[Native Shell](https://nsh.dev) and hosted on GitHub Pages.

## Plan

- Five training days a week: biceps, triceps, legs, back, chest.
- Log sets, reps and weight per exercise, and see progression over time.
- Local-only storage in the browser, with JSON export and import.

Status: naming and scoping. No code yet.
